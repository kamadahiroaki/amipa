# Exploring Linear

[日本語](../../ja/guide/03-linear.md)

Compare order, orientation, deletions and duplications, one row per haplotype.

## Four levels

Blocks › Anchors › Nodes › Bases. Narrow the range to go finer.

## Row order and the tree

The tree on the left is built from differences in the visible range. Click a branch to select its haplotypes.

## Pin rows

Right-click a row label. Reference haplotypes are pinned by default.

## Group and filter with a sample table

Load a TSV/CSV of sample attributes to group rows or show only listed samples.

## Link with the graph

Link: colour, follow or filter the graph by the Linear range.
