# Reads

[日本語](../../ja/guide/05-reads.md)

If the DB contains reads, they appear below the haplotype rows.

## Choose samples

Tracks › Reads › Samples. When rows are filtered, only matching samples.

## Labels (e.g. parent of origin)

In DBs with read labels, reads are grouped by label within a sample.

## Find a read

Find › Read. The path lights up in the graph and the row is outlined in Linear. Press Esc to clear.
