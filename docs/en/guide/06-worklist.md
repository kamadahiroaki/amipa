# Going through a list of sites

[日本語](../../ja/guide/06-worklist.md)

Load a BED, VCF or gene list, visit each site and mark it.

## Accepted formats

BED, VCF, JSON Lines, one item per line (gene, coordinates, node:).

## Keys

N next / P previous / L later / S skip / D done / E other end.

## Export

Marks and notes as JSON Lines.
