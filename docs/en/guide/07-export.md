# Exporting figures and data

[日本語](../../ja/guide/07-export.md)

Figures for papers and data for analysis.

## Figures

SVG (editable) and PNG for both the graph and Linear.

## Data

Subgraph (GFA), nodes (BED), row order (TSV), tree (Newick), base alignment (FASTA), per-haplotype coordinates (BED).
