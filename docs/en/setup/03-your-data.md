# Preparing your data

Requirements per input and what to do if they don't match.

## Graph (GFA)

GFA 1.0/1.1, no overlaps, compressed is fine, path name forms, non-integer ids are fine.

## How the reference is chosen

--ref-key → RS:Z → GRCh38 → CHM13 → first path.

## Genes (GFF/GTF)

File names per sample and sequence names.

## Reference annotations

Bands, genes, repeats, variants (VCF).

## Reads (GAF) and labels

GAF from giraffe etc., and read label tables.
