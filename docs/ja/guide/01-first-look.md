# はじめの 5 分

[English](../../en/guide/01-first-look.md)

デモサーバを開いて、グラフと Linear を一度ずつ動かす。

## デモを開く

デモの URL と、DB の選び方（上部の左の選択欄）。

## 画面の 3 つの部分

上部バー・グラフ・Linear。右パネルはノードかリードを選ぶと開く。

> [画面写真: 全体。各部分に番号]

## グラフを動かす

ドラッグで移動、ホイールで拡大。拡大すると細かい層に切り替わる。

## 遺伝子へ移動する

上部の Find で Gene を選んで名前を入れる（例: TP53）。

## Linear を開く

上部の Linear。グラフで見ている範囲が下に株の行として並ぶ。

## 次に読むもの

目的別の章へのリンク。
