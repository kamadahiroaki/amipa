# Linear を見る

[English](../../en/guide/03-linear.md)

株ごとの行で、並び・向き・欠失・重複を比べる。

## 4 つの段

Blocks › Anchors › Nodes › Bases。範囲を狭めると細かい段へ。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - Linear: 下部のパネルに、各ハプロタイプのコンティグが合意座標をどう通るかを、ブロック › 錨の列 › ノード › 塩基の段で並べる（再編成・逆位・重複・アレル）。範囲をグラフに写して絞る・塗る・寄せる

## 行の並びと系統樹

左の木は表示範囲の配列の違いから作る。枝のクリックで株を選ぶ。

## 行を固定する

行ラベルの右クリック。参照の株は最初から固定。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - 行の固定と並べ方: 行ラベルの右クリックで、合意列などの見出しや株の行を上に固定する。株の属性表（TSV・CSV）を読み込み、属性や遺伝子の状態で群に分けて並べる。表にある株だけを出すこともできる

## 属性表で分ける・絞る

TSV/CSV の株の属性を読み込み、群に分ける。表にある株だけを出す。

## グラフと連動させる

Link: 範囲をグラフで塗る・寄せる・絞る。
