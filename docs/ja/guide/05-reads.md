# リードを見る

[English](../../en/guide/05-reads.md)

DB にリードが入っていると、株の行の下に並ぶ。

## 出すサンプルを選ぶ

Tracks › Reads › Samples。株を絞っているときは対応するサンプルだけ。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - リード: Linear の各行の下に整列したリードを、段に応じて深さ・棒・塩基で出す（DB にリードが入っている場合）。塩基の段は「株数 × 範囲の bp」が 1,200 万までの範囲で開く（90 株で約 100 kb）。Linear が使えないパスの無いグラフでは、旧版の Alignment でノードを並べてリードを見る

## ラベル（由来など）

ラベルがある DB では、サンプルの中がラベルごとにまとまる。

## リードを探す

Find › Read。グラフで経路が光り、Linear で行が枠で囲まれる。Esc で解除。
