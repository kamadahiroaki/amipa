# 地点の一覧で順に見る

[English](../../en/guide/06-worklist.md)

BED・VCF・遺伝子名の一覧を読み込み、1 か所ずつ見て印とメモを付ける。

## 読み込める形式

BED、VCF、JSON Lines、1 行 1 項目（遺伝子名・座標・node:）。

## キー操作

N 次 / P 前 / L 後で / S スキップ / D 済 / E もう一方の端。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - 地点の一覧: BED・VCF・遺伝子名や座標の一覧を読み込み、1 か所ずつ移動して「後で見る」「スキップ」「済」の印とメモを付ける（キー操作 N・P・L・S・D）。印とメモは JSON Lines で書き出せる

## 書き出す

印とメモを JSON Lines で。
