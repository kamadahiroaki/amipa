# 図とデータを持ち出す

[English](../../en/guide/07-export.md)

論文の図と、解析に使うデータの書き出し。

## 図

グラフ・Linear とも SVG（編集できる）と PNG。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - 図版の書き出し: 表示中の内容を SVG で保存する

## データ

部分グラフ（GFA）、ノード（BED）、行の並び（TSV）、系統樹（Newick）、塩基の整列（FASTA）、株ごとの座標（BED）。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - Linear の書き出し: 図（SVG・3 倍の PNG、全行）、系統樹（Newick）、並び（TSV）、範囲の中の各株のコンティグ座標（BED）、ブロック × 株の表、塩基の段の整列（FASTA）
> - 部分の書き出し: 表示範囲の部分グラフ（GFA）とノード集合（BED）
