## 表示が重いとき

設定 › 表示予算を下げる。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - 大きな DB を見るとき: 初回の表示が遅い場合、原因はほぼディスクのランダム読みにある。DB はローカルディスクに置く（ネットワークストレージや FUSE は桁で遅くなる）。メモリを増やすと、よく見る範囲がページキャッシュに残って速くなる

## URL で共有する

表示位置と設定が URL に入る。

> 下書きの材料（旧 usage-viewer.md より。ガイドを書くときに使い、書き終えたら消す）
>
> - 共有 URL: 表示位置と設定を URL に載せて共有・復元する
> - 編集を保存させない配信（AMIPA_READONLY=1）: 編集モード自体は使える。ノードを動かして繋がりを確かめる使い方はデモでもそのまま通り、結果が DB に残らないだけになる。動かした状態は共有 URL には載る。Edit 行の Save は最初から無効表示
