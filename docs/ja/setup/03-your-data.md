# 自分のデータを準備する

[English](../../en/setup/03-your-data.md)

入力ごとの条件と、合わないときの直し方。

## グラフ（GFA）

GFA 1.0/1.1、重なりの無いもの、圧縮のままでよい、パス名の形、整数でない id も可。

## 参照の決まり方

--ref-key → RS:Z → GRCh38 → CHM13 → 先頭のパス。

## 遺伝子（GFF・GTF）

株ごとのファイル名と配列名の対応。

## 参照の注釈

染色体バンド、遺伝子、反復、変異（VCF）。

## リード（GAF）とラベル

giraffe などで整列した GAF、リードのラベル表。
