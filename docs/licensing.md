# ライセンス

| 対象 | ライセンス | 理由 |
|---|---|---|
| `prep/`（前処理） | GPL-3.0-or-later | Infomap（GPL-3.0-or-later）を同一プロセスで読み込むため |
| `viewer/`（閲覧） | MIT | コピーレフトの依存が無く、他のソフトに組み込みやすくするため |
| ドキュメント | CC BY 4.0 | |

リポジトリ直下の `LICENSE` は GPL-3.0（全体としての条件）、`viewer/LICENSE` が MIT です。
同梱物の一覧と入手元は [`../NOTICE`](../NOTICE) にあります。

## コンテナイメージを再配布するとき

イメージには GPL のソフトウェア（Infomap、および Debian のシステムパッケージ）が入っています。
そのまま再配布する分には、次の 2 つを満たせば足ります。

1. `NOTICE` を一緒に配る（イメージ内 `/opt/amipa/NOTICE` にも入っています。`amipa licenses` で表示できます）
2. GPL コンポーネントの対応するソースの入手方法を示す。同梱しているのは無改変の公開版なので、
   `NOTICE` に書いた入手元と版番号を示せば足ります

自分で改変した Infomap を含めて配布する場合は、その改変ソースの提供義務が生じます。

## AMIPA を組み込みたいとき

- 閲覧側だけを使う（アトラスを表示する機能を自分のソフトに組み込む）→ `viewer/` は MIT なので自由
- 前処理を含めて使う → GPL-3.0-or-later に従う（派生物も GPL で公開する）

前処理を permissive にしたい場合は、Infomap を別プロセスとして呼ぶ形に変えれば分離できます
（現在は Python API を同一プロセスで使用）。必要であれば issue で相談してください。
