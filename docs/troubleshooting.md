# うまくいかないとき

## 閲覧

| 症状 | 原因と対処 |
|---|---|
| アトラスが一覧に出ない | `DB_DIR` の指定間違い。`amipa check` で見えるか確認する |
| 整列パネルだけ出ない | `.distill` が無い、またはシンボリックリンクのまま移動した。`check` が警告する |
| リードだけ出ない | `reads/` の実体がアトラスに入っていない。索引だけでは表示できない |
| 検索やハプロタイプ絞り込みが無い | その索引を作らずにアトラスを構築している。`check` が指摘する |
| 最初の操作が遅い | ディスクのランダム読み。ローカルディスクへ置く／メモリを増やす |
| 表示が一部欠ける | 重い要求が上限で打ち切られている。`AMIPA_MAX_ROWS` / `AMIPA_FETCH_MS` を緩める |

## 前処理

| 症状 | 原因と対処 |
|---|---|
| `Killed` で落ちる | メモリ上限。コンテナなら `--memory` を増やす。段ごとの目安は [usage-prep.md](usage-prep.md) |
| 一時領域が足りない | `--tmp`（本体を組む場所）と `--spill`（一時ファイル）を**別々に**指定する |
| 極端に遅い | `--tmp` が共有ファイルシステムを指している。起動時のログに選ばれた場所と種別が出る |
| リードがほとんど捨てられる | GAF のノード ID がアトラスの葉と一致していない。`--named-coordinates` で整列したか確認する |
| 出力が root 所有になる | `-u $(id -u):$(id -g)` を付けて実行する |

## コンテナのビルド

| 症状 | 原因と対処 |
|---|---|
| 依存の取得で止まる | ビルドには外向き通信が要る。プロキシ環境では設定を渡す |
| Apptainer の build がマウントで失敗 | サイト設定の bind。`env -u APPTAINER_BINDPATH apptainer build ...` |
| 権限の拒否で起動できない | 元ファイルの権限がイメージに入り込んでいる。同梱の定義は対策済み |
| ライブラリが見つからない | 実行段のイメージに共有ライブラリが不足。同梱の定義は `ldd` で検査してから焼く |
| 変な `import` エラー | ホストの `~/.local` を拾っている。`--cleanenv` と `PYTHONNOUSERSITE=1`（同梱イメージは設定済み） |
