# アトラスを見る（`amipa serve`）

```bash
docker run --rm -p 3001:3001 -v /path/to/graph.amipa:/data:ro <registry>/amipa-viewer serve
# → http://localhost:3001
```

- 開けるポートは **1 つだけ**（画面も API も同じプロセスが配る）
- アトラスは**読み取り専用**でマウントしてよい
- 複数のアトラスを見せたいときは、それらを含む親ディレクトリを `/data` に渡す

## 設定

| 環境変数 | 既定 | 意味 |
|---|---|---|
| `DB_DIR` | `/data` | アトラスの置き場 |
| `PORT` | `3001` | 待ち受けポート |
| `SESSION_DIR` | — | 共有 URL 用スナップショットの保存先（唯一の書き込み先） |
| `AMIPA_READONLY` | — | `1` で編集の保存を禁止。**公開時は必須** |
| `AMIPA_CACHE_MB` | 64 / 512 | 接続ごとのページキャッシュ。小メモリ機では下げる |
| `AMIPA_DB_WORKERS` | CPU 依存 | 読み取りワーカー数 |
| `AMIPA_MAX_ROWS` / `AMIPA_FETCH_MS` | — | 1 リクエストの上限（重い表示要求で全体が詰まるのを防ぐ） |
| `AMIPA_PREWARM` | — | 起動時に読み込んで温めるアトラス名。**メモリに載る見込みがあるときだけ** |

死活確認は `GET /healthz`、版の確認は `GET /api/version`。

## 主な機能

| | 内容 |
|---|---|
| **多解像度表示** | ズームに応じて表示する層が自動で切り替わる。粗い層は 1 ノードが多数の実ノードを代表する |
| **ハプロタイプ・リボン** | どのサンプル/ハプロタイプがどの経路を通るかを帯で表示。サンプルを選んで絞り込める |
| **アノテーション** | 染色体バンド・遺伝子・領域でノードを着色、ラベル表示、名前や座標で移動 |
| **参照座標** | `chr:位置` で移動。ノードに参照座標を重ねて表示 |
| **バブルの整列** | バブル内の各アレルを多重整列として表示し、FASTA/CLUSTAL/表で書き出せる |
| **リード整列** | 下部パネルに塩基レベルのリードを表示（アトラスにリードが入っている場合） |
| **図版の書き出し** | 表示中の内容をベクタ形式（SVG）で保存 |
| **共有 URL** | 表示位置と設定を URL に載せて共有・復元 |
| **部分の書き出し** | 表示範囲の部分グラフ（GFA）とノード集合（BED） |

## 大きなアトラスを見るとき

初回の表示が遅い場合、原因はほぼ**ディスクのランダム読み**。

- アトラスは**ローカルディスク**に置く（ネットワークストレージや FUSE は桁で遅くなる）
- メモリを増やすと、よく見る範囲がページキャッシュに残って速くなる
- `AMIPA_PREWARM` は**アトラス全体がメモリに載る見込みがあるときだけ**有効
